# Launch Types — PLF, Audience, Signature, Evergreen

Four launch types cover most offers. Each has a different shape, calendar, and conversion pattern. Pick the one that matches the offer, the audience, and the operator's capacity.

---

## 1. PLF (Product Launch Formula)

**Origin:** Jeff Walker's Product Launch Formula. The most-used launch type for information products.

**Shape:** Pre-launch content (3–5 days of free value) → Cart opens for 5–7 days → Cart closes.

**When it works:**
- New mechanism, new category, or new way of doing things.
- Warm list that's engaged but hasn't seen this offer yet.
- Offer is mid-ticket ($500–$5k).
- You have 2–3 weeks of pre-launch runway.

**Cart window:** 5–7 days.

**Conversion pattern:** Strong open-cart day, mid-week dip, strong close-cart day.

**Capacity:** PLF works for unlimited buyers (digital products) or cohort caps (cohort courses).

**Anti-pattern to avoid:** PLF without a real mechanism to teach in pre-launch. The pre-launch has to deliver value, not just tease.

---

## 2. Audience Launch

**Origin:** More recent. The launch is shaped around an existing audience, not a new mechanism.

**Shape:** Existing content + relationship → Direct offer → Short cart window (3–5 days).

**When it works:**
- Strong existing audience that knows and trusts the operator.
- Offer fits the audience's existing problem space.
- Operator doesn't need to teach a new mechanism — the audience already wants the result.
- Cart window is shorter because the audience is warm.

**Cart window:** 3–5 days.

**Conversion pattern:** Front-loaded (most buyers convert on day 1–2 because they're already primed).

**Capacity:** Whatever the operator can fulfill.

**Anti-pattern to avoid:** Audience launch without an audience. If the operator has 200 email subscribers and 500 Twitter followers, this isn't an audience launch — it's a signature launch.

---

## 3. Signature Launch

**Origin:** The original launch type (before PLF). The first-time launch of a flagship offer.

**Shape:** Longer pre-launch (7–14 days of anticipation) → Cart opens → Cart closes over 7–10 days → Bonus round for last-minute buyers.

**When it works:**
- First time launching this offer.
- Building from scratch (small list, growing audience).
- High-ticket offer that needs more setup.
- Operator has runway to do a longer launch.

**Cart window:** 7–10 days.

**Conversion pattern:** Slow build (most buyers convert in the last 3 days).

**Capacity:** Whatever the operator can fulfill.

**Anti-pattern to avoid:** Signature launch for a warm audience that doesn't need the buildup. Use audience launch instead.

---

## 4. Evergreen Launch

**Origin:** The launch is always on. Buyer joins any time. No deadline pressure.

**Shape:** Landing page → Email nurture → Buy any time → Trigger-based emails (welcome, abandoned cart, post-purchase).

**When it works:**
- Self-paced info products.
- Low-ticket ($50–$500).
- Scalable fulfillment (no cohort, no live calls).
- Operator doesn't have time for live launches.

**Cart window:** Continuous.

**Conversion pattern:** Steady, lower than cohort launches (typically 30–50% of cohort launches at the same traffic).

**Capacity:** Unlimited (or whatever the operator caps it at).

**Anti-pattern to avoid:** Evergreen for high-ticket or cohort-based offers. The lack of urgency kills conversion. Also avoid evergreen with fake countdowns — buyers can tell.

---

## Picking the right launch type

| If your situation is... | Use this launch type |
|--------------------------|----------------------|
| New mechanism, warm list | PLF |
| Strong existing audience, fit offer | Audience launch |
| First time, building from scratch | Signature launch |
| Self-paced, low-ticket, scalable | Evergreen |
| Cohort-based course with limited seats | Signature or audience (with cohort cap) |
| High-ticket B2B | Custom (not these four) |

---

## Launch type vs. offer type

| Offer type | Best launch type |
|------------|------------------|
| Info product ($200 course) | PLF or evergreen |
| Cohort course ($2k) | Signature or audience |
| 1:1 coaching ($5k+) | Audience (sales-driven) |
| Mastermind ($25k+) | Audience or custom |
| Self-paced digital | Evergreen |
| High-ticket B2B ($50k+) | Custom / sales-led |

---

## Launch type by audience size

| Audience size | Best launch type | Why |
|---------------|------------------|-----|
| <500 email subscribers | Audience + signature | Build list first, then launch with what you have |
| 500–2,000 | Signature or PLF | Enough for a real launch |
| 2,000–10,000 | PLF or audience | Mature list — choice based on offer |
| 10,000+ | Any | Mature list — choice based on operator preference |

---

## Conversion benchmarks by launch type

These are rough benchmarks. Actual conversion depends heavily on offer strength, list quality, and traffic.

| Launch type | Typical conversion (cold) | Typical conversion (warm) |
|-------------|---------------------------|---------------------------|
| PLF | 1–3% | 3–7% |
| Audience | 3–5% | 5–15% |
| Signature | 1–3% | 3–8% |
| Evergreen | 0.5–2% | 1–4% |

"Conversion" = buyers / unique visitors to the sales page. Above benchmarks suggest the offer is strong and copy is working. Below suggests a leak in offer, copy, or pricing.

## Combining launch types

Some operators combine:

- **PLF + audience launch** — pre-launch content for new buyers, direct offer to existing audience. Common for established operators.
- **Signature + evergreen** — first launch is signature, then convert to evergreen. Common for new offers.
- **Audience launch + cohort cap** — audience launch with limited seats. Drives urgency.

Combining works when each layer is real. Layering fake urgency on real urgency doesn't.

## Launch type anti-patterns

### Evergreen with fake countdowns
"5 hours left!" on an always-on offer. Buyers can tell. Use real cohort cap or accept lower conversion.

### PLF without pre-launch value
The pre-launch emails should teach. If they just tease, the launch feels like a bait-and-switch.

### Audience launch without an audience
200 email subscribers isn't an audience. Use signature launch and grow the list.

### Signature launch for warm audience
If the audience already knows the offer fits, the long buildup is friction. Use audience launch.

### First launch as evergreen
First launch should be signature or PLF — building the list and the launch list is part of the work. Evergreen doesn't build the launch list.

### Re-launching as the same launch type
If a signature launch flopped, switching to PLF won't fix it. Diagnose: was it the offer, the copy, or the list? Fix the leak.

## Decision framework

```
Is this your first launch of this offer?
├── Yes → Signature launch
└── No → Do you have a warm list (2,000+)?
    ├── Yes → Is the offer a new mechanism or category?
    │   ├── Yes → PLF
    │   └── No → Audience launch
    └── No → Build list first (signature-style launch with lead gen)

Is this self-paced, low-ticket, scalable?
├── Yes → Evergreen (after first signature/PLF launch)
└── No → Don't use evergreen
```

---

## When to switch launch types

| Situation | Switch to |
|-----------|-----------|
| First launch succeeded, doing it again | Audience launch (warmer list now) |
| List has grown significantly | PLF or audience (depending on offer) |
| Want to scale without live launches | Evergreen (after first successful cohort launch) |
| Adding a new mechanism to existing offer | PLF (need to teach the mechanism) |
| Launching a new offer to existing list | Audience launch (list knows you) |
| Want recurring launches without rebuilding | Evergreen with cohort windows |

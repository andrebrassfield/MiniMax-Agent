## Lessons for the next REFRESH / dossier cycle

- **PDFs returned via webfetch as raw binary are a known edge case.** The mitigation is to either (a) accept secondary-corroboration and flag weight reduction, or (b) re-fetch via a different method (e.g., GitHub's pdf2text, or a direct curl to the PDF and pdftotext). The current dossier chose (a) for clm-2026-06-05-007; (b) should be tried on the next REFRESH.
- **The Federal Register notice + FDA meeting page + Regulations.gov docket form a tight primary triangle** for any FDA advisory committee meeting. All three cross-reference the same docket number and the same date/time/location, making cross-source agreement check very efficient. This pattern generalizes to any future PCAC meeting handoff.
- **Number-family distinctions (12 / 7 / 13) are the highest-risk downstream Scribe confusion.** The dossier leads with this distinction in the "Contradictions" section; the Scribe handoff should explicitly carry this distinction forward.

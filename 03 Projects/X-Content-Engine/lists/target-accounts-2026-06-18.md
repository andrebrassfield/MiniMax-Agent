# Target Accounts — v1 Seed (50 mid-size niche accounts)

The v1 seed for the X-Content-Engine reply-guy targeting. Curated from:
1. The initial seed in `reply-guy-strategy-2026-06-18.md` (the strategy doc)
2. The 3 targets from today's v1 batch proof-of-concept (already engaged)
3. The search results from the niche queries (2026-06-18 10:54 CT)

Follower counts are **approx** (rounded to nearest 5K or 1K). The reply-guy
skill verifies the engagement-velocity score at sweep time before
prioritizing — the v1 list is a starting point, not a fixed ranking.

## Format

```
| Handle | Name (if known) | Followers (approx) | Tier | Pillar fit | Activity | Notes |
```

**Tier definitions:**
- **A:** 5K-50K followers, niche overlap. The reply-guy sweet spot.
- **B:** 50K-500K, niche adjacent. Bigger reach, less targeted.
- **C:** 1K-5K, hyper-niche match. Smaller but high-engagement audiences.
- **D:** 500K+. Avoid unless trending (buried otherwise).

**Pillar codes (from `agents/persona.md`):**
- **P1:** E-Commerce Logistics (Shopify, TikTok Shop, fulfillment)
- **P2:** The Trades (HVAC, plumbers, owner-operators)
- **P3:** Existential Macro (GEO, AI search, brand entities)
- **P4:** Build Logs (Claude Code, voice agents, FSM wrappers)
- **P5:** Leverage Play (job defense, AI for knowledge workers)
- **P6:** Hype Translator (AI tool drops, contrarian-hype, cultural obs)

**Activity:** HIGH = posts multiple times/day, fresh content always available.
MEDIUM = posts 1-3x/week. LOW = posts rarely (<1x/week, target for engagement but check first).

## Notes for the weekly recalibrator

1. **The "approx" follower counts are guesses.** The recalibrator should
   verify each account's follower count + engagement-velocity at Week 1's end
   (2026-06-25) and re-tier based on actuals. The current tier assignments
   are starting estimates.

2. **@ levelsio, @sama, @ylecun, @karpathy, @Shopify** are listed for reference
   but the reply-guy skill MUST filter them out (Tier D, avoid unless trending).

3. **Already-engaged accounts (michaelheredia, spandan_madan, svpino)** are
   in the v1 seed but the reply-guy skill should NOT re-reply to the same
   target post within 7 days. Future sweep runs should target different posts
   from the same accounts.

4. **Cold accounts (low recent activity)** should be checked for freshness
   before being added to a sweep. The x-niche-scraper integration verifies
   the post is <2h old, so a cold account can still be a target if they're
   active today.

5. **The list should grow to 50-100 accounts by Week 2.** The Researcher
   can expand via: (a) "accounts that follow X" lookup, (b) reply-guy
   sweep discovery (when a high-engagement post comes from an account not
   in the list, add it), (c) Andre's manual additions.

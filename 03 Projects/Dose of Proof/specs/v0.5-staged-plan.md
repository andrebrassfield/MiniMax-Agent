# v0.5 — LLM Prompt Calibration Sprint

## Sprint origin

Per `specs/v0.4-review-package.md` §9.4.1 sign-off B (locked 2026-06-26 11:54 CT):
- v0.4 LLM path is structurally correct but operationally over-flagging (33% FPR on CLEAR posts)
- Citation gate (v0.5 staged) is production-ready and ships independently
- v0.5 sprint focuses on LLM prompt calibration only — no other engine work in this sprint

## Sprint scope (single-track, narrow)

**In scope:**
1. LLM system prompt calibration (require EVIDENCE before flagging)
2. CLEAR-example demonstrations added to LLM system prompt (when NOT to flag)
3. Temperature tuning (0.1–0.3 for classification)
4. Hybrid weight rebalancing (LLM as second opinion vs fail-closed override)
5. Extended regression set: re-run §2 with 12 examples + add 8 new CLEAR educational posts to prove <10% FPR

**Out of scope:**
- Regex layer changes (already 12/12 PASS, leave alone)
- Citation gate changes (already 4/4 PASS, shipped)
- Engine runtime config (provider, baseURL, apiKey — already verified live)
- New channels, new post types, new compliance rules
- Performance optimization (separate sprint after FPR clears)

## Acceptance criteria

| Gate | Target | Evidence required |
|---|---|---|
| **G1: FPR on CLEAR posts** | <10% (≤1 of 12 §2 + 8 new CLEAR examples) | `scripts/run_section2_llm_live.py` re-run with extended regression set |
| **G2: TPR on SENSITIVE posts** | ≥90% (no regression on the 4 SENSITIVE examples) | Same script |
| **G3: No fabricated citations** | 100% (all 4 citation-gate regression tests still PASS) | `scripts/run_citation_gate_tests.py` re-run |
| **G4: Hybrid fail-closed union** | Combined gate (regex ∪ LLM ∪ citation) ≤10% FPR + ≥90% TPR | End-to-end on extended regression set |
| **G5: Re-screen of v0.4 examples** | All 12 §2 examples classify right | `scripts/run_section2_llm_live.py` (must include 4 SENSITIVE catches preserved) |
| **G6: Hard interlock respected** | Engine HALTED state honored by any cron firing during calibration | `~/.mavis/state/dop-engine-halt.state` + cron prompt frontmatter check |
| **G7: Sprint review** | Co-CEO sign-off on v0.5 calibration results | New §11 appended to `specs/v0.4-review-package.md` (or v0.5-review-package.md if scope warrants) |

## Calibration plan (ordered)

### Phase 1 — Prompt architecture (LLM-only, no engine wiring)

- [ ] Rewrite LLM system prompt: require EVIDENCE (cite specific phrase) before flagging
- [ ] Add CLEAR-example demonstrations (5-8 examples) showing when NOT to flag
- [ ] Lower temperature to 0.2 (deterministic for classification)
- [ ] Add explicit "when in doubt, do not flag" closing rule
- [ ] Test prompts via `scripts/run_section2_llm_live.py` with single-call mode (no engine integration)

**Target after Phase 1:** FPR on §2 examples drops from 33% to ≤15%.

### Phase 2 — Hybrid rebalance (LLM as second opinion)

- [ ] Change hybrid from fail-closed UNION to weighted majority (regex HIGH, LLM MEDIUM, citation HIGH)
- [ ] LLM flags become advisory unless they cite a specific phrase pattern regex would miss
- [ ] Test via `scripts/run_section2_llm_live.py` with hybrid mode

**Target after Phase 2:** FPR drops to ≤10%, TPR holds ≥90%.

### Phase 3 — Extended regression set

- [ ] Author 8 new CLEAR educational posts from existing FINAL assets:
  - 2 from `assets/social/4-traps/` (already locked FINAL)
  - 2 from `assets/social/x-thread-2-pcac-framework.md` (already locked)
  - 2 from `assets/social/pcac-peptides/2026-07-01-bpc-157.md` (observational only)
  - 2 from `assets/emails/substack-welcome-1.md` (educational only)
- [ ] Add 4 new SENSITIVE examples (1 fabricated PMID like fb-004-rev1, 1 dosing directive, 1 sourcing link, 1 testimonial-adoption)
- [ ] Run full extended regression (20 total: 12 original §2 + 8 new CLEAR + 4 new SENSITIVE — adjust to fit)
- [ ] Capture results in `specs/v0.5-calibration-results.md`

**Target after Phase 3:** All acceptance gates G1-G6 PASS.

### Phase 4 — Sprint review + sign-off

- [ ] Append §11 to `specs/v0.4-review-package.md` (or new file) with calibration results
- [ ] Co-CEO reviews results against G1-G7
- [ ] If all PASS → sign-off → engine flip ON at next cron window after hard interlock removal
- [ ] If any FAIL → diagnose → iterate Phase 1-3 → re-review

## How to add a new account

1. Andre says "scrape the structure of @new_account" or "pin @new_account to the source list"
2. The skill runs on the new account
3. If the output is usable (per the discipline checks in `tests/discipline-checks.md`), Andre approves adding it to this list
4. The Mavis-side EA appends a row to this file

The list is the canonical source of "who the Scribe studies." New
accounts go through one full run + Andre approval before being added.

## How the Scribe uses this

The Scribe reads the latest blueprint for each pinned account before
drafting a new post. The blueprint's "Notes for the Scribe" section
+ "Single Most-Copyable Move" are the actionable inputs.

If the Scribe is producing Pillar 3 content (contrarian thesis) and
GergelyOrosz is on the list, the Scribe's draft is benchmarked
against the GergelyOrosz blueprint — same pacing range, same
human-marker density, same bait/switch pattern.

## Why the list is small

3 accounts is the deliberate starting set. Each account takes ~30
minutes to scrape and produce a high-quality blueprint. Adding more
accounts = more Scribe-study-time per draft, which dilutes the
Scribe's voice focus.

When to expand: when the Scribe's drafts plateau (engagement stops
growing despite the same voice), the next move is either (a) add a
contrasting account to the list (different style) or (b) replace a
plateaued account with a fresher one.

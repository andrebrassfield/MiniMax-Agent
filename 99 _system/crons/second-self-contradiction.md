# Second-Self Contradiction Check — Daily 07:00 CT

The cron that reads `02 Notes/ideas/` against the last 30 days of `02 Notes/articles/` and surfaces ONLY conflict. Per the 2026-06-22 Path A spec — closes the gap between "I have ideas" and "I know which ones are no longer true."

The article is explicit: "Your only job is contradiction. Do not look for agreement. Find the conflict."

**EXECUTE the procedure:**

## Step 1 — Gather input set

**Ideas** (the positions to test):
```bash
find ~/MiniMax-Agent/02\ Notes/ideas -type f -name "*.md" 2>/dev/null | sort
```

**Sources** (the last 30 days of articles):
```bash
find ~/MiniMax-Agent/02\ Notes/articles -type f -name "*.md" -mtime -30 2>/dev/null | sort
```

**HALT** if ideas set is empty (nothing to check). Exit silently with `<mavis-progress>second-self-contradiction: skipped — 0 ideas</mavis-progress>`.

## Step 2 — Read the input set

For every idea: extract the core position (1-2 sentences). Skip notes that are pure capture without a stated position.

For every source: extract the key claims that could conflict with the ideas.

## Step 3 — Run the contradiction prompt

> Read my 02 Notes/ideas/ notes alongside source notes I have captured in the last 30 days. Your only job is contradiction.
>
> For each idea, tell me whether any recent source note contradicts, complicates, or materially updates that position. Do not look for agreement. Find the conflict.
>
> If there is no conflict for a given idea, say so in one word: **Clear**.

Discipline:
- Do NOT list agreements. If the source supports the idea, that doesn't appear here.
- "Complicates" counts — sources that don't directly contradict but introduce friction count.
- "Materially updates" counts — sources that don't say "you're wrong" but reveal new evidence count.
- The threshold for inclusion: would Andre, reading this output, change his position OR investigate further?

## Step 4 — Write the contradiction check

Output to `00 Inbox/contradiction-check-YYYY-MM-DD.md` (mirror to `~/MiniMax-Agent/99 _system/contradictions/contradiction-check-YYYY-MM-DD.md`).

```markdown
---
date: YYYY-MM-DD
type: second-self-contradiction
ideas_checked: <N>
sources_checked: <M>
conflicts_found: <K>
---

# Contradiction Check — YYYY-MM-DD

> Auto-generated by `second-self-contradiction` cron. Read this with coffee. The whole point is the things you didn't see.

## Active conflicts

### Idea: <idea title>
- **Source:** <article title>
- **Conflict type:** contradicts | complicates | materially updates
- **The friction:** <2-3 sentences>
- **Action:** <one of: revise the idea / read the source fully / sit with the tension>

(repeat for each active conflict)

## Cleared (no conflict found in last 30d)

- **<idea title>** — Clear
- **<idea title>** — Clear
(list all ideas that came back Clear)

## What this means

<2-4 sentences: the pattern across today's conflicts. If 5+ ideas came back Clear, that's data — Andre's positions are stable. If 3+ came back with conflicts, that's data too — the vault is moving faster than his position update.>
```

## Step 5 — Surface (only when conflicts found)

If `conflicts_found >= 1`: send a Telegram nudge with the count + the single most-actionable conflict (the one with the cleanest "Action:" line).

If `conflicts_found == 0`: silent. The output is on disk for the weekly deep session to consume.

## Hard constraints

1. **No agreement-finding.** The article is explicit. If the brief reads like "sources support your position X," the cron is broken.
2. **"Clear" is the default, not a failure.** Most ideas will come back Clear. That's the data point: most of Andre's positions are stable against recent sources. Don't pad.
3. **Contradiction types are specific.** distinguishes contradicts / complicates / materially updates. Don't merge them.
4. **No cross-team reads.** Same as morning brief.
5. **Append to log.** Every run appends to `~/.mavis/state/second-self-contradiction.log`.

## Failure modes

| Failure | Detection | Recovery |
|---|---|---|
| Ideas set has 100+ notes (too many to read in one cron) | Step 1 audit returns >100 | Cap to most-recently-modified 30 ideas; note the cap in output |
| Source set is empty (no articles in last 30d) | Step 1 audit returns 0 sources | HALT — there's nothing to check against |
| Conflicts all read the same (LLM reflex, not real conflicts) | Step 4 output has uniform structure | Log warning; investigate the prompt |
